# 运维工具箱

提供在线和离线两个入口，转换和证书解析始终在浏览器本地执行。

- **在线团队版**：启动下述服务后访问 `http://127.0.0.1:4173/`。账号密码登录，配置和版本保存在服务端 SQLite；生成页面为 `../ops_toolkit_online.html`，须通过服务访问。
- **离线版**：[../ops_toolkit.html](../ops_toolkit.html)，可直接打开；数据在当前浏览器中，不提供账号权限控制，也可作为旧数据导出入口。

## 在线启动

使用 Node.js 24，在 `Toolkits/Tools/ops-toolkit` 目录执行：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run init-admin
npm.cmd start
```

初始化会交互询问管理员用户名和初始密码，密码输入隐藏，不接受命令行密码参数。用户名为 3～64 位字母、数字、点、下划线或短横线；密码为 12～128 字符。首次登录必须修改密码并重新登录。没有默认账号或密码，数据库已有账号时不能重复初始化。

默认监听 `127.0.0.1:4173`，按 Ctrl+C 停止。与离线静态服务使用相同默认端口，请选择一种服务启动，或设置不同端口。

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `OPS_TOOLKIT_PORT` | `4173` | HTTP 端口 |
| `OPS_TOOLKIT_HOST` | `127.0.0.1` | 监听地址，建议保留本机并使用反向代理 |
| `OPS_TOOLKIT_ORIGIN` | `http://127.0.0.1:4173` | 浏览器实际访问的来源地址，须与 Host、Origin 一致 |
| `OPS_TOOLKIT_DB` | `data/ops-toolkit.sqlite` | 数据库路径，相对当前工作目录；初始化与启动须使用同一路径 |

团队部署由 HTTPS 反向代理转发到本机 HTTP 服务，代理保留浏览器访问的 Host。例如设置 `OPS_TOOLKIT_ORIGIN=https://tools.example.com`；非本机来源必须使用 HTTPS，Cookie 自动加 Secure。服务端校验 HttpOnly／SameSite 会话、同源来源和 CSRF 令牌，不开放跨域 API，也不信任客户端的转发来源头。

SQLite 保存密码哈希及配置原值，应限制数据目录的系统访问权限；同一数据库只运行一个服务实例。`data/`、SQLite 及 WAL 文件已加入忽略规则。完整服务备份应先停止服务，再复制整个数据目录；页面备份仅包含业务数据，不含账号、密码哈希和会话。

## 在线账号与版本

| 操作 | admin | operate | readonly |
| --- | --- | --- | --- |
| 查询配置、版本与差异，临时转换和证书解析 | ✓ | ✓ | ✓ |
| 新增、编辑、复制、归档及删除配置 | ✓ | ✓ | — |
| 保存、恢复、清理版本，导入导出及下载 | ✓ | ✓ | — |
| 创建白名单账号、启停用户、角色分配与重置密码 | ✓ | — | — |
| 管理 region、环境类型、配置名称和有效组合 | ✓ | — | — |
| 本人改密、退出、切换本机主题 | ✓ | ✓ | ✓ |

启用账号即白名单成员，不开放自行注册。“用户管理”支持用户名、角色和状态筛选，禁止停用或降级最后一个管理员。改密、重置、角色变化和停用撤销已有会话；会话最长 8 小时。readonly 不触发业务写入；各角色查看同一工作空间，本期没有项目或字段级保密授权。

在线配置统一保存格式化 JSON，以「region、环境类型、配置名称」三项组合唯一定位。管理员在环境信息管理维护枚举及有效组合，保存时下拉选择。重复组合需确认覆盖；停用项保留查询和导出，阻止新提交。

配置默认三列表格（名称、值、说明），配置值进入 JSON 编辑器修改，旁侧可搜索、定位和编辑字段说明。所有修改仅在点击「保存版本」时提交；在线版不自动保存草稿或归档。版本包含完整快照、说明、服务端记录的编辑者／提交者用户名和 UTC 时间。格式变化不产生重复版本，历史恢复只载入编辑器，仍需手动保存。切页、换配置和退出有未保存提示，刷新／关闭使用浏览器原生提示。

配置及版本可按 region、环境类型全量导出（包含归档及停用项，不含未保存内容）。schema3 包超过 20 MiB 时生成 ZIP 记录分片，校验全部分片后事务导入。可预览冲突、整项跳过或指定有效新身份导入副本。历史作者标为未验证；账号、密码和会话不进入配置包。readonly 无任何下载／导出入口。

升级前停止服务并备份整个 data 目录（包括 SQLite 和 WAL 文件），再替换源码、构建并启动。旧 v1/v2 数据保留在待映射区，管理员逐配置选择三项组合；不猜测旧项目与环境。非法或未提交内容作为恢复资料保留，可下载、载入修复后手动保存或明确放弃。旧 IndexedDB 不自动上传或删除。

登录失效时页面清理共享数据，未保存编辑仅在当前页面内存暂存，重新登录同一账号可恢复；退出、换账号或刷新不会跨账号保留。网络失败不降级为无鉴权离线写入。

## 离线使用

直接用 Chrome 或 Edge 打开 `Tools/ops_toolkit.html`，即可使用转换和证书解析。本地存储状态显示在右上角；若浏览器不允许存储，工具进入临时模式。

长期管理配置建议使用固定本地地址。在此目录执行：

```powershell
npm.cmd run serve
```

浏览器访问 `http://127.0.0.1:4173/`。后续保持协议、主机名和端口一致，才能访问同一份本地数据。服务仅监听本机回环地址，不接收上传，不提供业务 API。

## 离线兼容能力

- **env / JSON**：env YAML（含 `env:` 或裸数组）、env JSON 数组、普通 JSON；自动识别、双向转换、递归排序、升降序、复制与下载。严格检查重复键、值类型、精度与深度，保留 `valueFrom` 引用。检测到 Kubernetes 变量展开时保留 env 原序。
- **证书解析**：PEM 粘贴、单张 DER、多文件选择与拖入、多张 PEM；显示 Subject、Issuer、有效期、SAN、用途、约束、算法、公钥参数及 SHA-256 指纹。未知扩展以 OID 展示，单张错误与其他证书隔离。
- **配置管理**：项目 / 环境 / 配置集，新增、筛选、搜索、重命名、标签、描述、跨环境复制、归档和删除；文本或 env 表格编辑，800 ms 草稿自动保存。
- **版本归档**：首次保存即生成 v1；有效改动在闲置 2 秒且距上次归档至少 60 秒后自动归档；支持手动归档、备注、语义差异、文本对照、恢复为新版本、旧版本清理。恢复前草稿单独保留并可下载。
- **备份**：全量或单配置集完整备份、脱敏分享、导入校验与预览、同名冲突跳过、导入为独立副本。数据库写入在事务中完成，多标签页修改有冲突检测。
- **界面**：中文、深浅主题、窄屏布局、键盘焦点、示例和错误反馈。

## 离线常用流程

1. 选择输入 / 输出格式，粘贴配置后点击“转换配置”。结构化 env JSON 数组可保留 Secret / ConfigMap 等引用；JSON 对象不能承载这些引用。
2. 点击“保存到配置集”，填写项目、环境和名称，也可选择更新现有同类型配置。纳管后启用草稿与版本管理，临时转换页不自动保存输入。
3. 在“配置管理”中编辑，分别留意“草稿已保存”和“已归档为 vN”。可点击“保存版本”立即归档。
4. 在“版本归档”中比较历史版本或当前草稿，恢复时创建下一版本。恢复前未归档草稿可在配置详情底部下载。
5. 定期在“数据备份”中下载完整备份。导入不会覆盖原有工作空间，同名项目副本会附加后缀。

敏感字段按名称建议遮罩，也可在配置元数据中手动指定：env 使用名称，JSON 使用 JSON Pointer（例如 `/database/password`，`~1` 表示 `/`，`~0` 表示 `~`）。每行一个标记；前缀 `!` 表示显式取消敏感标记。勾选“显示并编辑敏感内容”后可编辑原值。

## 范围与数据行为

- 完整 Deployment / Pod 提取、`.env`、ConfigMap 专用转换、证书台账和 Git 同步未纳入本次交付。在线账号及团队存储见上文。
- 离线数据在 IndexedDB 中，在线已纳管配置保存在服务端。完整备份含原值，遮罩并非加密。
- 自动排序采用 Unicode 码点字典序。JSON 数组顺序不变；对象键次序及空白变化不产生新版本；env 数组顺序变化会产生版本。
- Kubernetes 名称先做非空、可打印 ASCII 且不含 `=` 的检查；不符合传统名称形式时提示检查目标集群兼容性。工具不连接集群进行实际校验。
- 不处理 YAML 别名、锚点、合并键、显式标签和多文档。未知 env 字段会报错，不会静默删除。
- 证书只解析公开信息和时间有效性，不验证信任链、签名或吊销，不支持私钥、CSR、PFX/P12。
- 配置最大 1 MiB，env 最多 5,000 项，嵌套深度最多 100；证书合计 5 MiB / 50 张。旧离线备份最大 20 MiB；在线包超过 20 MiB 使用 ZIP 分片，每片不超过 20 MiB，导入总量保护上限 1 GiB。
- 历史默认不自动清理。多个标签页发生数据冲突时，先下载尚未保存的草稿，再到备份页重新载入本地数据。

## 开发与验证

需要 Node.js 24 或兼容依赖要求的更新版本。在本目录运行：

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd run test:browser
npm.cmd run test:online
node tests/performance.mjs
```

`test:browser` 默认使用已安装的 Chrome，不下载额外浏览器；运行 Edge 检查：

```powershell
$env:OPS_BROWSER = 'msedge'
npm.cmd run test:browser
```

源码按转换、证书、存储和交互拆分，构建后写入 `../ops_toolkit.html`。修改源码后请重新构建，不要直接修改生成文件。浏览器测试使用独立临时上下文及独立本地服务，不读取用户浏览器资料；截图和测试备份写入已忽略的 `test-output/`。

| 文件 | 用途 |
| --- | --- |
| `src/core.js` | 严格解析、转换、排序、内容摘要与差异 |
| `src/certificates.js` | ASN.1 / X.509 解析及有效期 |
| `src/store.js` | IndexedDB 事务、草稿、版本与备份 |
| `src/app.js` | 五个模块的交互 |
| `src/online.js` / `src/online-*.js` | 在线手动提交、说明、环境枚举、迁移和证书交互 |
| `src/config-model.js` / `src/archive.js` | JSON／YAML识别、说明定位、快照摘要和 ZIP 记录分片 |
| `src/api.js` / `src/identity.js` | 在线业务命令、登录、用户管理与会话隔离 |
| `server/` | SQLite、认证授权、配置命令、同源 API、初始化与启动 |
| `src/index.html` / `src/styles.css` | 页面结构及样式 |
| `build.mjs` | 在线与离线两个 HTML 入口的构建 |
| `tests/` | 核心、数据库、证书、真实浏览器及性能验证 |

依赖版本已固定在 `package.json` 和 `package-lock.json`。第三方许可证见 [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt)，也随生成 HTML 一同内嵌。YAML 使用 `yaml`，证书使用 `pkijs` / `asn1js`，SHA-256 使用 `@noble/hashes`；运行时没有 CDN 请求。

唯一完整需求设计及版本记录位于 [Design-doc 统一需求目录](../../../Design-doc/ops_toolkit/README.md)。

环境信息管理由管理员维护三项枚举。新增枚举保留当前字典和组合表单选择；选定 region、环境类型后，可搜索并多选配置名称，一次分配多个组合。已停用组合保持停用，可用“启用组合”单独恢复。

枚举和组合删除前显示影响清单，可取消、保留配置或同步删除配置。保留时环境项从管理选项隐藏，历史仍可查看、比较、导出，可复制到其他有效环境继续维护；同步删除会连同历史、恢复资料和保存回执一并清除。并发修改导致 409 时必须核对最新预览并再次确认。补充浏览器验证：`node tests/environment-browser.mjs`。
